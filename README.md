# Chandan Shinde | Portfolio

An interactive portfolio website built with modern web technologies.

## 🛠️ Tech Stack

* **Core:** React.js (v18+)

* **Build Tool:** Vite

* **Styling:** Tailwind CSS

* **Icons:** Lucide React

* **Deployment:** Static Site (Ready for AWS Amplify / GitHub Pages)

## ⚡️ Quick Start

1. **Clone the repository:**

   ```bash
   git clone [https://github.com/yourusername/chandan-portfolio.git](https://github.com/yourusername/chandan-portfolio.git)
   cd chandan-portfolio
   ```

2. **Install dependencies:**

   ```bash
   npm install
   ```

3. **Start the development server:**

   ```bash
   npm run dev
   ```

4. **Build for production:**

   ```bash
   npm run build
   ```

## ⚙️ Customization

* **Update Content:** Open `src/App.jsx` (or `Portfolio.jsx`) and modify the `PORTFOLIO_DATA` constant at the top of the file.

* **Update Images:** Place your profile image in `src/assets/` and update the import statement in the main component.
